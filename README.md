### Immune landscape characterization of neurofibromas with atypical features in Neurofibromatosis 1 reveals PD-1 and the Tim-3/Galectin-9 pathway as potential therapeutic targets

This repository contains the code to ensure the traceability of the analysis of single-cell RNA Sequencing data from the raw count matrices to the figures in the associated publication. Please open the [index.html](https://audrey-onfroy.github.io/Brunet_et_al_scRNASeq_NF1_2026/) file in any browser, and navigate through all files in this repository.

The results behind this analysis are published in Acta Neuropathologica Communications:

> Brunet *et al.*, Immune landscape characterization of neurofibromas with atypical features in Neurofibromatosis 1 reveals PD-1 and the Tim-3/Galectin-9 pathway as potential therapeutic targets, doi: [10.1186/s40478-026-02310-1](https://doi.org/10.1186/s40478-026-02310-1)
